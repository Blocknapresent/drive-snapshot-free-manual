## 🛠 Feature Breakdown

### Feature 1 — Full Drive Image
Create a complete snapshot of any partition or physical drive, including the system drive.

### Feature 2 — Incremental Backups
Save only changes since the last snapshot for fast, small delta files.

### Feature 3 — Virtual Mount
Mount any image as a virtual drive and browse files without restoring.

### Feature 4 — Full System Restore
Recover a system in minutes from bare metal, USB, or WinPE.

### Feature 5 — Scheduling
Automate snapshots with Task Scheduler or the built-in CLI.

### Feature 6 — Verification
Hash checks, logs, and integrity reports for every image.

## 🔧 Setup Walkthrough

### Step 1 — Prepare
Choose the source drive and pick a destination (external or network).

### Step 2 — Create First Image
Run Drive Snapshot and select the source.

### Step 3 — Save Full Image
Write a `.SN1` file to your destination.

### Step 4 — Add Incremental
Enable delta mode for the next run.

### Step 5 — Mount and Verify
Mount the image as a virtual drive to browse files.

### Step 6 — Restore if Needed
Boot from WinPE and restore from the image.
